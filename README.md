My entry for make.fun's "Two-Sentence Horror" competition: exactly two sentences, 173 characters — "Since my hearing aid was fitted, I can hear my dead husband humming in the kitchen every evening. The audiologist says the device only amplifies sound — it cannot invent it." The second sentence turns the first: a hearing aid can only amplify sound, never invent it — so the humming is real, and it has been there all along, unheard until now.

## Run it

```sh
python3 main.py
```

This writes the two-sentence story to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set) and prints it.
